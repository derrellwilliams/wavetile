# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- Preferred: use **Report a vulnerability** on this repository's Security tab (GitHub private vulnerability reporting).
- Or email realslimscrawny@gmail.com with "Wavetile security" in the subject.

Include the app version and build (Settings shows both), your iOS version, the steps to reproduce, and what an attacker could gain. Please don't include real server addresses, passwords or access tokens.

You should get a reply within a week. Wavetile is maintained by one person, so fixes ship in the next App Store release; please allow time for that before publishing details.

## Supported versions

Only the latest App Store release receives fixes.

## Scope

In scope: the Wavetile iOS app and its widget extension (this repository), and the wavetile.com site in `site/`.

Out of scope: Jellyfin server vulnerabilities (report those to the [Jellyfin project](https://github.com/jellyfin/jellyfin/security)), and podcast feeds or directories run by third parties.
